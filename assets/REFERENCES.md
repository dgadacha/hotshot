# HOTSHOT — Les 26 références 3/4

**26/26 images générées**, une référence PNG par asset, dans la direction artistique cartoon industrielle HOTSHOT.

Chaque image a été vérifiée visuellement : asset entier, silhouette lisible et cohérence de palette. Les 26 PNG ont été ouverts et leur canal de transparence vérifié. Ce sont les références pour générer les GLB ; les PNG de HUD seront livrés avec les modèles selon le processus convenu.

Les [dimensions et consignes de production](ASSET_PRODUCTION.md) complètent ces images. Dépose ensuite les fichiers dans [incoming/](incoming/), avec le nom indiqué sous chaque référence.
