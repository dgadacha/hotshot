# Déposer les assets HOTSHOT

Dépose ici le GLB et le PNG avec le **même nom de base**, selon le [catalogue de production](../ASSET_PRODUCTION.md).

Exemple :

```text
weapon_assault_rifle.glb
weapon_assault_rifle.png
```

Le PNG destiné au HUD doit avoir un fond transparent, sans texte ni interface. Les fichiers originaux déposés seront conservés ; l’intégration Three.js utilisera une copie normalisée si des ajustements sont nécessaires.

Lors du dépôt, indique simplement le nom de l’asset. Si le personnage possède un rig ou des animations, précise ceux qui sont inclus. Les modèles et les images seront inspectés avant intégration.
